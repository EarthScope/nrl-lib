=======
History
=======

2024.1.0.0
-----------

- The first release of the NRL library

2025.1.0.0
-----------
- Added logging functionality to track user interactions
- Improved performance of existing functions
- Fixed bugs related to case sensitivity in user inputs

1.0.0 (2026-11-05)
------------------
- Standardized package versioning on the 1.0.0 release schema
- Renamed the distribution to nrl-lib (the import name is still nrl)
- First release on conda-forge
- Raised the minimum supported Python version to 3.11
- Migrated packaging from setup.py to pyproject.toml
- Fixed missing logging.config in installed packages
- Removed unused runtime dependencies (configobj, types-requests)

1.0.1 (2026-11-09)
------------------
- First release on PyPI (pip install nrl-lib)
- Moved the source repository to GitHub (https://github.com/EarthScope/nrl-lib)
- Replaced GitLab CI with GitHub Actions, including automated PyPI publishing
- Clarified the package description and keywords
